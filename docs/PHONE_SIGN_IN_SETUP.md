# Authentication methods

FeedForward offers email/password and Google sign-in and account creation. Mobile-number sign-in, SMS account creation, and profile-based mobile login linking have been removed.

Contact phone fields remain available for delivery coordination; they do not enable authentication. Existing account records and contact details are preserved.

Deploy the updated application to remove these options from the interface. This code change does not change the hosted Supabase Phone provider setting.
